# Lab 03 - GAN Latent Gallery

## Certificate connection

Build Basic Generative Adversarial Networks: demonstrates how movement in a compact latent space can change a generated sample.

## Workflow

The user changes two latent coordinates, a seed, and a visual style. A deterministic generator maps those inputs to a repeatable SVG composition and four nearby variations.

## Implementation

`ganLatentModel.js` validates coordinates and creates deterministic shape, palette, and signature data. `GanLatentGallery.jsx` renders that data as accessible SVG artwork.

## Tests

Tests cover determinism, coordinate/seed sensitivity, invalid controls, variation count, and coordinate bounds.

## Limitations

The project visualizes latent-space ideas but does not train or execute a GAN. Its SVG shapes are generated by a transparent deterministic algorithm.
