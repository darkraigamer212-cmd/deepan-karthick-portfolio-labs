# Lab 03 - GAN Latent Gallery

## Certificate connection

Build Basic Generative Adversarial Networks: demonstrates how movement in a compact latent space can change a generated sample.

## Workflow

The user changes two latent coordinates, a seed, and a visual style. A deterministic generator maps those inputs to a repeatable SVG composition and four nearby variations. A designer or student can select the main sample or any variation and download it as a reusable 1600 x 1600 SVG background.

## Implementation

`ganLatentModel.js` validates coordinates, creates deterministic shape, palette, and signature data, and serializes a standalone SVG with an accessible title, description, provenance, and reproducibility metadata. `GanLatentGallery.jsx` renders the gallery, selection state, and download action.

## Tests

Tests cover determinism, coordinate/seed sensitivity, invalid controls, variation count, coordinate bounds, stable export content, XML escaping, embedded metadata, and filesystem-safe filenames.

## Limitations

The project visualizes latent-space ideas but does not train or execute a GAN. Its SVG shapes are generated by a transparent deterministic algorithm, and the exported metadata says so explicitly.
