# Batch 4 Prior-Art and Differentiation Note

Date checked: 2026-08-22

## Method and claim boundary

Searches covered the proposed project names and their closest functional categories: cloud TCO and lock-in assessment, AWS outage/GameDay planning, Azure identity blast-radius and access review, cloud-transformation assessment, subnet overlap detection, and network change planning. Public search cannot prove that no similar implementation exists anywhere. These projects are therefore described as original implementations with distinctive workflow combinations, never as verified worldwide first inventions.

## Findings

- Cloud cost/TCO calculators and cloud lock-in guidance already exist. Lab 11 differs by joining user-supplied planning economics to exactly five failure stories, early warnings, reversible responses, a pilot contract, and an independent exit test.
- AWS GameDay and resilience guidance already exists. Lab 12 differs by generating the rehearsal from ordered customer-journey steps and requiring symptom, evidence, containment, fallback, and recovery proof on every card.
- Azure access-review and identity blast-radius products already exist, including graph and attack-path tools. Lab 13 does not imitate those products; it creates an owned joiner/mover/leaver handoff and evidence checklist from a small local roster.
- Migration assessments and cloud-transformation advice already exist. Lab 14 differs by turning an executive promise into a falsifiable hypothesis, reversible pilot, assumption ledger, evidence gates, stop/continue triggers, and sponsor memo.
- Subnet calculators, IP address managers, overlap detectors, and network-design tools already exist. Lab 26 differs by withholding execution when deterministic blockers exist and composing verification, rollback, and stakeholder communication from before/proposed inventories.

- Stormspotter Azure attack-path tooling: https://github.com/Azure/Stormspotter

- General cloud portability and hybrid-cloud evaluation guidance: https://layer27.com/blog/cloud-workload-portability-in-2026-why-lock-in-is-the-new-migration-risk and https://plow.net/cloud-backup/hybrid-cloud-strategy-evaluation/

## Acceptance conclusion

No exact project-name match was found in the dated search, but that is not proof of global novelty. Batch 4 passes because each lab avoids a commodity clone and has a concrete, documented differentiator that produces an actionable artifact for a named user.
